# 个人 AI 投研助手

面向个人使用的 A 股研究项目。当前为**项目骨架**，尚未接入实时行情、交易接口或可用于投资决策的策略。

## 目录

```text
src/ai_research/
  config/         配置读取与参数约定
  data/           A 股行情、财报、资金、新闻的接入与标准化
  indicators/     MA、MACD、KDJ、RSI、BOLL
  fundamentals/   营收、净利润、ROE、PE/PB
  capital/        成交量、资金流、龙虎榜
  sentiment/      新闻抓取、去重、情绪分析
  factors/        技术、基本面、资金、情绪、行业因子
  backtest/       时间序列回测、成本与绩效
tests/            数据契约和计算测试
docs/             数据来源、字段口径与阶段记录
```

每个目录目前只有包入口或说明文档；模块实现需随数据口径确定后逐步加入。数据流建议为：数据源适配器 → 标准化与质量检查 → 本地存储 → 指标/因子 → 回测 → 报告。原始数据与派生数据分开保存，并记录来源和更新时间。

## 阶段 1 开发顺序

1. **1A 数据底座**：选一个有授权且适合个人使用的 A 股日线来源；先取得股票列表、交易日历、复权日线，确定代码、时区、交易日、复权、停牌、缺失值口径。实现增量拉取、重试、去重、校验和落库。先用少量股票验证，再扩大范围。
2. **1B 技术指标**：在统一日线数据上实现 MA、MACD、KDJ、RSI、BOLL；明确预热窗口与缺失值处理，用已知样本验证。
3. **1C 基本面与资金**：加入财报、估值、成交量、资金流和龙虎榜；分别记录公告日与可用日，避免未来信息泄漏。核对数据源是否提供所谓“主力资金”及其统计口径。
4. **1D 新闻舆情**：接入许可来源，按时间与股票关联，去重并保存原文链接、发布时间和模型版本；人工检查情绪结果。
5. **1E 因子与回测**：建立因子注册、行业归属与时间戳约定；回测纳入交易费用、滑点、涨跌停、停牌和可交易性约束，按时间划分样本内外。

阶段 1 的首个验收目标：给定股票代码和日期区间，可重复取得、校验、存储并查询日线数据；测试可在无网络环境运行。指标、新闻、因子和回测的目录并不表示这些功能已完成。

## 环境

推荐 Python 3.11+，每个项目单独创建虚拟环境：

```bash
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell
# .venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python -m pytest
```

把本地密钥放在环境变量或未提交的 `.env` 中；不要提交密钥、数据库文件和下载的行情。依赖来源及版本在实际选定数据源时补充，并锁定可复现版本。

## 数据库建议

阶段 1A 先用 **SQLite**：免独立服务，适合个人电脑和小规模原型；用唯一键 `(symbol, trade_date, adjustment)` 避免重复日线，并记录 `source`、`fetched_at`。通过 repository 层隔离 SQL。数据量或并发需求明显增加后再评估 PostgreSQL；大量历史分析可补 Parquet 文件。数据库迁移需保留字段口径和版本，不能把复权价格与未复权价格混在同一序列。
